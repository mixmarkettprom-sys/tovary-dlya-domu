Як отримати APK з планшета:
1. Створіть безкоштовний акаунт на GitHub.
2. Створіть новий репозиторій (можна Public) і назвіть його tovary-dlya-domu.
3. Розпакуйте цей ZIP. Завантажте ВСІ файли та папки з кореня проєкту у репозиторій.
4. Відкрийте вкладку Actions → Build Android APK → Run workflow.
5. Після завершення відкрийте виконаний workflow, прокрутіть до Artifacts і завантажте TovaryDlyaDomu-debug-apk.zip.
6. Розпакуйте його на планшеті/телефоні. Всередині буде app-debug.apk. Відкрийте APK та встановіть.

GitHub Actions збирає APK на хмарному runner, тому Android Studio на планшеті не потрібна.
