Товари для дому — Android-проєкт

Це готовий Android Studio-проєкт, який відкриває робочу версію програми у WebView.

Щоб отримати APK:
1. Відкрити папку у Android Studio.
2. Дочекатися Gradle Sync.
3. Build -> Build APK(s).
4. APK буде у app/build/outputs/apk/release або debug.
